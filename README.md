# sedef-ios

A structured, self-directed curriculum in iOS engineering, built in public.
Started October 2026. Goal: junior iOS developer.

## About

Sedef University is my own academic program: weekly projects, midterms, finals and a final defense, all tracked in this repository.
Every week ends with something concrete: working code, a README or a demo.

## Structure

- `Week01-ExpenseTracker/`: Week 1 level assessment, built without tutorials
- `Notes/LearningLog.md`: daily learning log
- `Notes/gaps.md`: knowledge gaps I find along the way
